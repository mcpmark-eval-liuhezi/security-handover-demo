# Security maintainer handover brief

Outgoing maintainer: HeziLiu (account login).
Rotation window closes at the end of this quarter; the incoming maintainer must be able to re-run every part of the handover unaided before the pager transfers.

The numbered checklist below is the canonical onboarding text. Wherever it is stored during the handover, it must be copied word-for-word.

Onboarding checklist:

1. Confirm access to the maintainer account and list its repositories.
2. Review the open secret-scanning alerts and note how many are open.
3. Rotate the shared service credentials in the vault.
4. Acknowledge the handover pull request and leave a confirmation comment.
5. Subscribe to repository security notifications.
6. File any follow-up work as tracked issues, then archive this brief.

Sign-off: both maintainers initial after step 6 is complete.
